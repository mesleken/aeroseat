1. Mimarinin Temeli: 3-Tier Çapraz Doğrulama

AeroSeat, bağımsız bir sertifikasyon otoritesi çözücüsü olarak tasarlanmıştır. Sistemin fiziksel ve matematiksel bütünlüğü üç aşamalı bir yöntemle doğrulanır:

  • Level 1 (AeroSeat ↔ Chrono): Matematiksel modellerin (Rigid Body / Joint Dynamics) yapısal bütünlük testi.
  • Level 2 (Chrono ↔ Experimental): Açık kaynaklı referans motorunun (Project Chrono) gerçek testlerle uyumu.
  • Level 3 (AeroSeat ↔ Experimental): CS/FAR 25.562 standartlarında asıl sertifikasyon gereksinimi (HIC, Lumbar, Femur limit onayları).

3. Çekirdek Modüller ve Kod Altyapısı

3.1. HIC Biyomekanik Çözücüsü (biomechanics.py)

AeroSeat, ivme eğrisinin altındaki alanı (O(N²)) Sliding Window mantığıyla tarayarak en kritik t1-t2 aralığını (maks. 15ms veya 36ms) bulur.

def calculate_hic(self, time_s, accel_g, max_window_s=0.036):
    max_hic, best_t1, best_t2 = 0.0, 0.0, 0.0
    for i in range(len(time_s)):
        for j in range(i + 1, len(time_s)):
            dt = time_s[j] - time_s[i]
            if dt > max_window_s: break
            
            integral = np.trapz(accel_g[i:j+1], time_s[i:j+1])
            hic_val = dt * ((integral / dt) ** 2.5)
            
            if hic_val > max_hic:
                max_hic, best_t1, best_t2 = hic_val, time_s[i], time_s[j]
    return max_hic, best_t1, best_t2

3.2. Çapraz Doğrulama Regresyon Testleri (test_golden_reference.py)

Geliştirilen her yeni versiyonun, elde edilen kesin Geven S.p.A. sonuçlarıyla uyumlu kaldığını teyit eden otomatik test mekanizması.

def test_baseline_head_impact_occurs(base_golden_setup):
    seat = SeatModel(setback_mm=583, belt_type='standard')
    results = SledTest(seat, dummy, pulse).run()
    assert results.head_impact_occurred is True
    assert results.hic > 6000  # Gerçek deney: 6176.4
    assert 600 < results.max_head_accel_g < 700  # Gerçek deney: 649.0 g

def test_redesigned_no_head_impact(base_golden_setup):
    seat = SeatModel(setback_mm=583, belt_type='optimized')
    seat.apply_design_factors(ap_x=26, ap_y=44, d1=3.0, d2=3.0, d3=1.8, d4=2.0, d5=20.0, d6=1.5, d7=250.0)
    results = SledTest(seat, dummy, pulse).run()
    assert results.head_impact_occurred is False
    assert results.hic < 1000
    assert results.head_path_mm <= 555
